# michalaferber.github.io

The landing page at **<https://michalaferber.github.io/>** — the root of the
GitHub Pages user site, and the front door to the project sites published beneath
it at `michalaferber.github.io/<repo>`.

## What's here

- `index.html` — the page itself: a short introduction and links out to
  [techguywithabeard.com](https://techguywithabeard.com/),
  [michalferber.dev](https://michalferber.dev/) and the GitHub profile.
- `googlec76ba187942b30b0.html` — Google Search Console verification. It must
  stay at the root to keep the property verified.

## Deploying

GitHub Pages builds this from `main` directly — no Actions workflow, which is the
one deploy path for a project of this shape (§4).
